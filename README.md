# Приглашение • Империя Знаний

Театральное онлайн-приглашение с золотым занавесом, частицами света, RSVP-формой и уведомлениями в Telegram.

## Структура

```
.
├── index.html              ← главная страница
├── assets/
│   ├── style.css           ← стили (золото, занавес, анимации)
│   ├── app.js              ← занавес, частицы, RSVP, музыка
│   └── music.mp3           ← (опционально) фоновая музыка
├── guests.json             ← карта id → имя для именных ссылок
├── netlify/
│   └── functions/
│       └── rsvp.js         ← бэкенд: принимает ответы и шлёт в Telegram
├── netlify.toml            ← конфиг Netlify
└── README.md
```

## Что заменить (заглушки)

В `index.html` найдите все `[В КВАДРАТНЫХ СКОБКАХ]`:
- `[ВРЕМЯ]`, `[ТЕАТР ОПЕРЫ И БАЛЕТА]`, `[ДРЕСС-КОД]`, `[ДАТА]` (RSVP до), `[ТЕЛЕФОН]`
- `[ЗДЕСЬ КОРОТКОЕ ЛИЧНОЕ ОБРАЩЕНИЕ — ЗАМЕНИТЕ]`
- 4 пункта программы вечера

В `guests.json` замените `[ИМЯ ГОСТЯ N]` на реальные ФИО.

## Деплой на Netlify (3 минуты)

1. Зайдите на https://app.netlify.com → **Add new site → Deploy manually**
2. Перетащите всю папку проекта в окно загрузки
3. После деплоя откройте **Site settings → Environment variables** и добавьте:
   - `TELEGRAM_BOT_TOKEN` = `123456:AAH...` (ваш токен от @BotFather)
   - `TELEGRAM_CHAT_ID` = `987654321` (ваш chat_id)
4. Передеплойте сайт (Deploys → Trigger deploy → Deploy site)

## Получение chat_id

1. Напишите своему боту любое сообщение в Telegram
2. Откройте `https://api.telegram.org/bot<ТОКЕН>/getUpdates` в браузере
3. В ответе найдите `"chat":{"id":...}` — это ваш `chat_id`

## Ссылки для гостей

После деплоя у вас будет адрес вида `https://имя-сайта.netlify.app`.

- **Общее приглашение:**
  `https://имя-сайта.netlify.app/`
  (секция с именем будет скрыта)

- **Именные приглашения:**
  `https://имя-сайта.netlify.app/?n=g01`
  `https://имя-сайта.netlify.app/?n=g02`
  ... и так до `g20`

  Карта id → имя в `guests.json`. Можно использовать любые id (`anna`, `petrov` и т.п.)

- **Вариант без guests.json** (имя прямо в ссылке):
  `https://имя-сайта.netlify.app/?name=Анна%20Петрова`

## Что прилетает в Telegram

```
🎉 Анна Петрова — БУДУ
💬 «Поздравляю с юбилеем!»
🔖 id: g01
🕒 2026-05-10T14:32:00.123Z
```

Для отказа — `😢 ... — не смогу прийти`.

## Музыка (опционально)

Положите файл `assets/music.mp3` (рекомендуется лицензионно чистый трек, ~3-5 МБ). Кнопка ноты в правом нижнем углу включает/выключает фоновую музыку.

Если файла нет — кнопка просто не сработает, страница работает без него.

## Локальная проверка

Просто откройте `index.html` в браузере — анимации и форма работают.
RSVP-кнопка отправки выдаст ошибку (нет бэкенда локально) — это нормально, на Netlify заработает.
